InvestWatch

Automatyczny monitoring treści o instrumentach i usługach finansowych w polskim internecie — lokalne modele AI bez zewnętrznych API i chmury.

Problem rynku

Skala i ulotność naruszeń

Dynamiczny przyrost reklam inwestycyjnych w sieci i social mediach: promocja przez finfluencerów, brak lub ukrywanie ostrzeżeń o ryzyku oraz nielicencjonowane doradztwo poza rejestrem KNF.

Wyzwanie nadzoru

Ograniczenia ręcznego przeglądu

Ręczne przeglądanie setek stron i postów jest powolne, a agresywne kampanie reklamowe potrafią zniknąć w ciągu kilku godzin zanim analityk zabezpieczy materiał dowodowy.

collector i api — zbieranie treści oraz agregator wyników

collectorPlaywright + BullMQ
  • Aktywne adaptery (MVP): sample (dane offline + syntetyki gold set), web (Chromium, discovery z głębokości 1, rotacja 23 User-Agentów i PROXY_LIST, limit 2/host, jitter), youtube (publiczny RSS kanałów) oraz tiktok (pojedyncze filmy przez oEmbed + fallback JSON, #51).
  • Zakres social i ochrona SSRF (#74): adaptery FB/IG pozostają poza obecnym MVP (gotowy interfejs Adapter; filtr UI ukrywa nieaktywne typy z GET /sources). W ssrf.ts (isBlockedUrl + context.route) blokowane są żądania na loopback, sieci prywatne, link-local i usługi Compose.
  • Harmonogram i odporność: upsertJobScheduler wg sources.cron (Europe/Warsaw), semafor ANALYZE_CONCURRENCY=1, timeout 600 s, deduplikacja w locie, status partial przy błędzie analizy oraz jednorazowy retry po HTTP 502 (AI_RETRY_DELAY_MS, #90).
  • Zabezpieczenie dowodów: HTML + screenshot PNG w SeaweedFS S3, upsert w documents po url_hash, triggery first_seen_at / last_seen_at.
apiFastify + Drizzle
  • Agregator M1/M2/M3 (GET /documents, GET /documents/:id): składa osobne rekordy z findings w jeden ujednolicony obiekt dokumentu (modules: {"1","2","3"} + podsumowanie overall: maxScore, riskLevel, flaggedModules).
  • Śledzenie widoczności reklam M1 (004_seen_tracking.sql): triggery bazy utrzymują first_seen_at i last_seen_at, a API wylicza isActive (flaga false po późniejszym pełnym przebiegu ok z karencją 1 h, który nie znalazł URL-a).
  • Wyszukiwanie, audyt, kalibracja i zapisy: filtry z pg_trgm, zapis progu (PUT /settings/modules/:module) wywołujący POST /recompute-risk?module= w ai (#84), PATCH /findings/:id/status z SELECT ... FOR UPDATE, presigned URL (15 min) i opcjonalny ADMIN_TOKEN (#71).
  • Real-time & eksport: Socket.io (alert:new, finding:updated, crawl:status) oraz eksport CSV/JSON dla polskiego Excela (;, przecinek dziesiętny, BOM UTF-8, limit 10 000 wierszy).

Moduł 2/3 · Silnik analityczny AI

ai — preprocessing (tokenizacja i embeddingi) oraz M1 / M2 / M3

Python 3.12 · FastAPI · Ollama · 86 podmiotów KNF
Potok preprocessingu: trafilatura (czysty tekst) → deduplikacja (SHA-256 + 64-bit simhash na 3-gramach, próg Hamminga 6) → tokenizacja i embeddingi (tokenizacja leksykalno-fleksyjna z granicami słów dla aliasów KNF + wektory bge-m3 vector(1024) w pgvector) → routing do M1 / M2 / M3.
Trzy moduły analityczne (na main)Budżet 240 s
  • M1 (Finfluencerzy): wzmianka o firmie KNF (86 w entities.csv, polskie końcówki i anchory ±200 znaków) spoza official_domains/social_handles; prompt m1-v3 (wagi 0.7/0.2/0.1 na promocję, linki partnerskie/sponsorowane) + encja reklamującego advertiser_entity_id (resolve_advertiser, #83).
  • M2 (Informacja o ryzyku): ewolucja od 4 (m2-v1) i 8 kryteriów (m2-v3) do 16 kryteriów tekstowych (m2-v5 + pełna lista w schemacie JSON minItems/maxItems) zmapowanych na reguły 1, 2, 3, 6, 9–12b, 14–18 załącznika UKNF. 5 reguł układu graficznego (4, 5, 7, 8, 13) jest poza zakresem tekstowym.
  • M3 (Shadow advisory): nielicencjonowane doradztwo i zarządzanie portfelem wg art. 76 ustawy o obrocie (m3-v5 + m3-rules-v4, #95) z filtrowaniem klauzul disclaimerów (strip_disclaimers() po spójnikach przeciwstawnych — zastrzeżenie nie jest dowodem, lecz ukryta porada obok niego zostaje wykryta).
Dlaczego Bielik-11B + bge-m3?vs Gemma / BERT
  • SpeakLeash/bielik-11b-v2.3-instruct:Q4_K_M (Apache-2.0): natywny polski tokenizer i korpus → trafna interpretacja polskiej fleksji, języka reklam i terminologii KNF przy dyscyplinie schematu JSON (temperature: 0).
  • Zmierzone czasy na GPU (RTX 3060 12 GB): M1 / M3: 3,4–5,8 s · M2: 9–10,5 s · brak modułu: < 0,15 s (zimny start ~30 s).
  • bge-m3 (MIT) zamiast klasycznego BERT: okno do 8192 tokenów (16× więcej niż 512 w BERT), wielojęzyczne wektory 1024-dim dla całych publikacji w tym samym serwerze Ollama.
